For machines

This site is built to be read by software as well as by people. These are the files published for that purpose.

  • sitemap.xml
    The standard sitemap, listing every page with its last modified date and a priority. Linked from robots.txt.

    https://alphaflux.net/sitemap.xml

  • robots.txt
    Crawl rules. Everything on this site is public product documentation, and answer engines and AI crawlers are explicitly welcome across all of it rather than tolerated.

    https://alphaflux.net/robots.txt

  • llms.txt
    A short index written for language models: what the platform is, what each module does, the pricing structure and how the discount programs work.

    https://alphaflux.net/llms.txt

  • llms-full.txt
    The full text of every page in one file, so an answer engine can read the whole site without fetching each page separately.

    https://alphaflux.net/llms-full.txt

  • Structured data
    Every page publishes structured data describing the organisation, the breadcrumb trail, and where relevant the product, the plans and the questions answered on the page. The markup and the visible content match, because structured data describing something the page does not say is a lie told to a machine.

    application/ld+json on every page

  • The API specification
    A machine readable description of the platform's own interface, for developers and for agents. Issued with an API key.

    https://alphaflux.net/api/openapi.json

    • Questions people ask before signing up

    Why publish a file just for language models?

    Because a growing share of people find software by asking a question rather than by searching. A file that states plainly what the platform does, what it costs and what the limits are gives an answer engine something accurate to read. Publishing it is a way of being described correctly rather than being guessed at.

    Can I crawl this site?

    Yes. Everything here is public product documentation, the crawl rules permit the whole site, and no part of it requires JavaScript to read. Structured data is published on every page describing the same content a person sees.
